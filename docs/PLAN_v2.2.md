# v2.2 计划：贵宾更好懂 + 营业压力（2026-10-12）

玩家反馈：
> 贵宾招待还是太不明显了，所需要的东西不知道在哪里做。其他的东西有点过于简单，可以考虑要不要增加营业压力？现在其实挂机也能增加营业额

## 1. 贵宾：告诉玩家「去哪做」

v2.0.1 已经有头顶大金泡泡 + 3 格教学卡，但只说了「要什么」，没说「在哪做」。

- **做的地方会发光**：贵宾想要某样东西、而掌柜手上没有时，做它的地方（茶台、灶台、牛奶机、毛巾架……）一圈金光慢慢呼吸，头顶飘同一个物品图标 + 两个字的动词（「泡茶」「做饭」「拿奶」）。拿到手就停。
- **泡泡里画路线**：贵宾头顶的大泡泡里画「地方的小图 → 物品」，例如「茶台 → 🍵」，一眼知道去哪。
- **箭头分两段**：先指做的地方（箭头旁带那个地方的小图），拿到后再指贵宾。
- **每种愿望第一次出现**：一张图示卡「[茶台] → [🍵] → [贵宾]」，只出一次。
- **愿望要的东西必须已经能做**：贵宾不会要还没解锁的东西（比如食堂没开就不要会席）。
- 验收：从新玩家视角截一组图，每一步都能看出「下一步去哪」；机器人在不看箭头、只看发光处的模式下也能完成。

## 2. 营业压力：用心经营明显比挂机好，但永远不卡死

原则（WORKFLOW 第 3 节）：难度宁低勿高、不能卡死、没做到不罚到没法玩。压力 = **做得好有明显加成，偷懒就慢慢少赚**，而不是惩罚。

- **口碑（每天结算）**：每位客人离开时按体验打 1~5 星。看这几项：
  - 柜台等多久
  - 分到的房间干不干净
  - 想泡汤时有没有毛巾
  - 想吃饭时有没有饭
  - 生气走的直接算 1 星

  当天平均星数在傍晚的小结卡上显示。**口碑影响第二天的来客数和房费（±20%）**，人气榜的 ♥ 也按口碑加。差口碑只是少赚，不会倒闭。
- **傍晚高峰**：每天傍晚有 60 秒客人翻倍（HUD 一个小钟 + 一句「客人多起来了」）。忙得过来口碑更高、赚得更多。
- **挂机有上限**：每个鱼干堆、钱柜都有容量（大约 1~2 分钟的收入），满了就停止累积，堆上冒一个「满」字小泡泡。账房猫提高容量，但不会无限。挂机收入大致降到认真玩的 30~50%（现在是 77%）。
- **员工不是万能的**：员工效率随口碑和等级变化；高峰时还是需要掌柜亲自帮忙（接待、打扫、送毛巾）。
- **新手保护**：★2 之前没有高峰、口碑不影响收入；第一次出现时各有一张图示卡。
- 机器人验收：勤快 / 普通 / 新手照样都能到 ★5（新手 ≤ 60 分钟），永不卡死；挂机档收入比降到 30~50%；勤快的口碑中位 ≥ 4 星、普通 ≥ 3.5 星；「好不好玩」审查：压力是不是让人想动起来，而不是让人烦。

## 顺序

先等走路卡顿、门口卡住、出餐台抢饭团这三个修复合并，再按上面做（一个代理按顺序做，免得冲突），做完试玩、平衡、上线。
