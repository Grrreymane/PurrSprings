# 猫猫温泉旅馆 Purr Springs · 开发规格（MVP）

类型：走动式放置经营（idle arcade），参考 My Perfect Hotel / My Sweet Hotel。
一句话：你是猫掌柜，摇杆走路，**站到哪就自动干活**——前台接客、铺被子、给温泉送毛巾、捡客人付的小鱼干；
背着鱼干站到地上的「价格圈」里就能扩建、雇员工，最后把小旅馆做成五星温泉旅馆。

技术：沿用 `_workflow/template`（单文件 `index.html`、canvas、逻辑分辨率 180×320、`paint()` 像素画板、WebAudio 合成音、`save/load`）。
体验准则见 `D:/Minigame/_workflow/WORKFLOW.md` 第 3 节（不晃屏、少文字、操作提示清楚、不能卡死）。

## 2. 玩法循环

### 2.1 玩家

- 移动：**按住屏幕任意位置拖动 = 浮动摇杆**（按下处出现底座，拇指拖出方向，拖得越远走得越快，超过 14 像素算满速）；电脑上 WASD / 方向键也能走。右上角 18×18 是静音键（模板），按在那里不出摇杆。
- 碰撞：脚底一个 8×5 的盒子，对挡路格和挡路家具做 x、y 分轴处理（贴墙能滑着走）。
- 基础速度 56 像素/秒；「跑鞋」每级 +15%，共 3 级。
- 能顶着一摞毛巾走：基础容量 4 条；「竹篮」每级 +3，共 2 级。
- 走路动画 6 帧/秒两步交替；停下站立帧。毛巾摞在头顶，每条叠 2 像素，走动时上层略微滞后摇摆（柔和，不是抖）。

### 2.2 站在哪就干什么（每帧用玩家脚底点判定，都不用点按钮）

| 区域 | 效果 |
|---|---|
| 接待位 | 排在最前的客人「办入住」：每人 0.7 秒，头顶出进度圈。需要至少一间干净的空房，否则客人头上冒「床」气泡等着 |
| 鱼干堆 | 一踩就全部收走：钱立刻到账，飞几条小鱼到 HUD 的鱼干图标（最多 6 条粒子） |
| 脏房间的打扫区 | 打扫 1.5 秒（进度圈）；离开不清零，回来接着扫；扫完房间变干净 |
| 毛巾架 | 每 0.12 秒拿一条，直到拿满 |
| 毛巾篮 | 每 0.1 秒放一条，直到篮子满（10 条） |
| 价格圈 | 把身上的鱼干一点点倒进去（见 2.5） |

### 2.3 客人流程（状态机）

```
arrive   从门外走到队尾（队伍前移时自动跟上）
queue    排队；耐心 45 秒，耗尽 → angry（不付钱，头顶 💢 离开）
checkin  在最前排，有人（玩家或前台猫）在接待位且有干净空房 → 进度满：
         付房费到「前台鱼干堆」，分配房间（房间状态 reserved），
         温泉已开 → toBath，否则 → toRoom
toBath   走到毛巾篮旁 (6,5)
towel    篮里有毛巾：拿一条 → toSlot；没有：头顶「毛巾」气泡等，20 秒后放弃泡汤 → toRoom（不生气）
toSlot   有空泡汤位：预约并走过去 → bathing；没有：在等位点等（同样 20 秒后放弃）
bathing  进到水里 6 秒（画泡汤小猫，头顶小毛巾，热气），付泡汤费到「温泉鱼干堆」，换上浴衣，冒 ♥
toMilk   牛奶机已开：走到 (12,5) 买牛奶 1 秒，付牛奶钱到「牛奶鱼干堆」
toRoom   走到自己房间 (2,y0+1)（右房镜像）
sleep    躺进被褥 10 秒（被褥换 sleep 帧，冒 Zzz）
leave    房间变脏，房里出现小费鱼干堆；走到门外消失
```

- 出客：每隔 `spawnGap[star]` 秒来一位（第一位开局 1.5 秒就来）；条件是队伍未满 5 人且馆内未离开的客人数 < 已开房间数 + 3。
- 客人毛色随机（不与掌柜同为橘猫），衣服颜色随机；有一半拎着行李箱。
- 客人之间、客人与玩家之间都不碰撞（互相穿过）。寻路走格子 BFS（地图只有 510 格），沿格子中心走，速度 34 像素/秒 ±10%。

### 2.4 员工（价格圈雇来，雇来后从休息处走去上岗）

| 员工 | 毛色 / 衣服 | 行为 |
|---|---|---|
| 前台猫 recep | 三花 / 和服 | 一直站在接待位，算作「有人在接待位」 |
| 仲居猫 maid ×2 | 白猫 / 和服 + 白围裙 + 头巾 | 空闲时在休息位；挑最近的、没人认领的脏房去打扫（2.5 秒），扫完找下一间，没活就回休息位。**不捡钱**（钱留给玩家捡） |

### 2.5 价格圈（扩建 / 雇人 / 升级，**全部在地上，没有菜单**）

- 地上一个 16×16 的虚线圆角方框，中间是要解锁的东西的图标，下面写价格数字。玩家走近（2 格内）时在圈上方显示两个字的名称。
- 站在圈里就往里倒钱：速率 = max(15, 价格/1.2) 每秒，身上没钱就停；已倒的钱存档（`S.paid[id]`）；圈里的填充进度从下往上涨。
- 倒满 → 解锁：一圈柔和的星光 + 「啵」，东西弹出来（缩放 0→1.15→1，0.35 秒），存档。**不闪屏、不震屏。**
- 只有前置条件满足的圈才出现（出现时弹一下）；这样屏幕上永远只有 1~3 个「下一步」。

### 2.7 目标指引（箭头）——同时也是机器人的「大脑」

`guideTarget()` 每帧（或每 0.25 秒）算出当前最该去的地方，返回 `{x, y, kind}` 或 `null`。屏幕上：目标在画面内时，目标上方一个上下浮动的小箭头；在画面外时，屏幕边缘一个指向它的箭头。优先级：

1. 还没走过路（`S.tut.moved` 为假）：不画箭头，画「拖动的小手」+ 四个字「拖动走路」。玩家走了 40 像素后消失，永远不再出现。
2. 有客人在柜台等、没有前台猫、玩家不在接待位 → 接待位。
3. 有客人因为没有干净房间在等、有脏房、仲居不够（脏房数 > 仲居数）→ 最近的脏房。
4. 温泉已开、没有搬运猫、（篮子 ≤ 2 条 或 有客人在等毛巾）→ 身上有毛巾就指篮子，没有就指毛巾架。
5. 有买得起的价格圈（身上的钱 ≥ 还差的钱）→ 最便宜的那个。
6. 地上有鱼干堆 → 最大的那堆。
7. 否则 → 最便宜的可见价格圈（让玩家知道下一步是什么），玩家离它 2 格内就不画。

**箭头指的地方必须真能推进**（WORKFLOW 第 3 节）：比如第 3 条只有在「真的因为没房卡住」时才指脏房。

### 2.8 气泡（不写字，只用图标）

### 2.10 存档

```js
S = {
  v: 1,
  money: 0, earned: 0,
  unlocked: { room1: true },     // id → true
  paid: {},                      // id → 已经倒进去的钱
  basket: 0,                     // 篮里毛巾数
  piles: {},                     // 鱼干堆 id → 数额（recep / onsen / milk / room1..room8）
  rooms: {},                     // room1..8 → 'clean' | 'messy'（读档时 reserved→clean，occupied→messy 并给小费）
  stats: { guests: 0, angry: 0, time: 0 },
  tut: { moved: false },
  done: false,                   // ★5 庆祝看过了
}
```
- 键名 `save('state', S)`；有变化时最多每 2 秒存一次，切后台 / pagehide / 每次解锁立刻存。
- 读档：`S = Object.assign(defaults(), load('state', {}))`，嵌套对象也逐个补默认值；**永远不清玩家存档**。
- 客人、员工位置不存（读档后员工从休息处出发，客人重新来）。

## 3. 代码结构（index.html 内的分区，按顺序）

保留模板已有的分区，新增的用同样的 `// ====` 标题：

1. constants + helpers（模板）——新增 `TILE`、`PFONT`、`fontOf`
2. pixel painter（模板，不改）
3. **ART**：`/*ART:chars:BEGIN*/ … /*ART:chars:END*/`、`/*ART:env:BEGIN*/ … /*ART:env:END*/`、`/*ART:objects:BEGIN*/ … /*ART:objects:END*/` 三段。核心代码先在每段里放「占位版」实现（色块即可），美术稿完成后整段替换成 `art/*.js` 的内容。**核心代码只通过第 4 节的接口取图。**
4. screen + input（模板 + 摇杆 + 键盘）
5. audio（模板 + 背景音乐 + 音效）
6. drawing helpers（模板）
7. MAP & DATA：地图字符串、房间表、解锁表、星级表、物件表
8. state + save/load
9. pathfinding（BFS）+ movement/collision
10. entities：player / guests / staff
11. zones：接待、打扫、毛巾、鱼干堆、价格圈
12. guide（箭头）+ hints + bubbles
13. update(dt)
14. render：世界层（静态地块预渲染到 240×544 的离屏画布，解锁时重画）→ 地面层（价格圈、被褥、鱼干堆）→ 按脚底 y 排序的物件与猫 → 正门暖帘（盖在猫上面）→ 气泡、进度圈、头顶毛巾、箭头 → HUD → 文字
15. title / celebration / share card / cover
16. present + textSprite（模板）
17. boot（模板，保留 `/*TEST_HOOK*/`）

约定：
- `update(dt)` 只改数据、`render()` 只画；**不许在 render 里改游戏状态**。
- 逻辑里不用 `Date.now()`，用累计时间 `T`；随机用 `Math.random()`（headless `--seed` 会替换它）。
- 给机器人留的口子：`botMove = null | {x, y}`（非空时代替摇杆输入，长度 ≤ 1）；`newGame()` 开新档并进入游戏；`guideTarget()`；`findPath(tx0, ty0, tx1, ty1)` 返回格子路径。
- 性能：静态世界层只在解锁时重画；每帧只画可见区域；水面动画只画可见的水格。

## 4. 美术接口（核心代码与美术稿之间的合同）

所有函数**返回 canvas**（或 makeSpr 对象，下面注明），内部自己用 `art(key, () => …)` 缓存，同样的参数返回同一个 canvas。只能用模板的工具：`paint / rows / makeSpr / Grid / shade / mixHex / lit / eyeG / gLine / flipC / tintC / mk / OUT / R / clamp`。各文件内部的私有函数、常量加前缀（`_ch` / `_en` / `_ob`），避免重名。**不许用 `Math.random`**（要随机就用格子坐标做哈希）。

锚点约定：「锚点 (ax, ay)」指 sprite 里对准世界坐标的那个像素；画的时候 `drawImage(c, R(x - ax), R(y - ay))`。

## 5. 声音（全部 WebAudio 合成）

- 背景音乐：一首悠闲的和风小调（五声音阶，类似古筝的拨弦 = triangle + 快速衰减，加一个很轻的低音持续音），约 72 BPM，循环；独立的音乐总线，音量小（0.05 左右），切后台挂起（模板已处理 AC.suspend）。
- 音效：捡鱼干（轻快「叮」，连续捡时音高上升，限速）、倒钱进价格圈（滴答，越来越高）、解锁（琶音 + 风铃）、入住（柜台铃「叮——」）、打扫完成（刷一下）、拿 / 放毛巾（轻「啵」）、泡汤（入水的哗啦，lowpass 噪声）、牛奶（两声「咕嘟」）、客人开心（喵：音高 600→900→500 的滑音）、生气（低沉的「哼」）。

## 7. 验收标准

用 `node D:/Minigame/_workflow/tools/headless.js D:/Minigame/Hotelgame tests/bot.js --seed N` 跑（N = 1..6）：

- 跟着箭头走的「勤快玩家」（反应 0.3 秒、直接走最短路）：
  - 第一个价格圈（room2）在 **30~60 秒**买下；
  - 前 5 分钟每个解锁间隔不超过 60 秒；之后不超过 120 秒；
  - 全部解锁（★5）用时 **15~25 分钟**；
  - 雇了前台猫之后生气离开的客人 < 10%。
- 「普通玩家」（反应 1 秒、30% 的时间在乱逛或站着不动）：全部解锁 ≤ 40 分钟，没有卡死（任何时候 90 秒内总能再赚到钱）。
- 不变量（每秒检查）：钱 ≥ 0 且是整数、不是 NaN；每间房最多一个客人；每个泡汤位最多一个客人；篮子 0..10；没有客人在同一个状态里待超过 120 秒（除了 sleep / bathing 的固定时长）；`render()` 不抛错。
- 存档往返：任意时刻 `save` → 新开一局 `load` → 继续跑 5 分钟不报错，钱和解锁不变。

画面检查（`make_test_page.py` + `shot.py --size 540x960`）：标题、开局、温泉开放后有人泡汤、8 间房全开、★5 庆祝，每张都要好看、看得清、没有错位。
