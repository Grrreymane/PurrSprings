# v2.0 用户反馈 → v2.0.1 / v2.1 改动（2026-10-11）

用户原话：
> 完全没有学会怎么照顾贵宾，不知道它们想要什么。5星旅馆达成的时候就蹦出分享了，问题是我连所有房间还没有解锁。不喜欢端茶送牛奶，要不可以解锁店员去干这件事，要不就是设施开了以后npc自己去买，现在npc甚至在牛奶机前等我送牛奶。同理，我都解锁店员自动了，再有什么一次可以拿很多个有点鸡肋。捡鱼干范围增加总感觉没效果。然后音效不知道是什么有点吵，biubiubiu的。
> 美术上想加四季，老板的衣服，每个房间我其实想要的是地板壁纸不一样，特别是左边的那套房间和主空间一模一样一点新鲜感都没有。解锁樱花树和枫树，怎么只有一颗啊，干脆多种几颗。。然后下面的花园（有猫在睡觉的那个）感觉没有完成。两个温泉感觉没有美术上的差异化。
> 字体全用像素体吧，包括标题。

## 改法（已定，按这个做）

| # | 反馈 | 改法 | 谁 |
|---|---|---|---|
| G1 | 不会照顾贵宾，不知道想要什么 | 贵宾每个愿望都用**大图标气泡**挂在头顶（不靠愿望牌）；箭头旁显示该拿的东西的图标并先指取物点、再指贵宾；第一次贵宾出一组 3 格图示卡（迎宾 → 带去套房 → 照头顶图标拿东西）；愿望不限时也不失败，只是越快小费越多；做完一个愿望有明显的 ✓ 和台词 | 玩法 |
| G2 | ★5 一到就弹分享，房间还没开完 | ★5 只出横幅 + 「升星啦」，不弹面板；**全部客房和区域都开了**才出「全馆落成！」庆祝面板（带分享）；菜单「旅馆」页随时能分享 | 玩法 |
| G3 | 不喜欢端茶送牛奶；客人在牛奶机前等我送 | 设施开了以后**客人自己去买**（牛奶机、茶台，像 v1 牛奶机：站一下就付钱到鱼干堆）；客人再也不站在机器前等掌柜。房间呼叫改成**可雇的「茶房」员工**自动送（便宜、★2 就能雇）；没雇之前呼叫是可选的小费活，不接也不扣任何东西，箭头不强推 | 玩法 |
| G4 | 员工都自动了，「一次拿很多」的升级鸡肋 | 删掉托盘 / 竹篮扩容中后期那几级（员工接手以后没用的），只留开局第一级；省下的价格位换成有意义的东西（多种几棵树、房间装修等，见 A 组） | 玩法 |
| G5 | 捡鱼干范围升级没效果 | 去掉「鱼网只吸大堆」的限制（`NEAR_MIN`）；半径明显变大（每级 +1.5 格左右），范围内的鱼干**自动飞过来**；买的时候和走动时画一个淡淡的圈让人看见范围 | 玩法 |
| S1 | 音效 biubiubiu 吵 | 常响的音效全部换软：`pop`（上滑音 = biu）、`coin`（方波连音）、`tick`（倒钱滴答）、`click/page`（方波）改成低一点的正弦 / 三角、更短更轻、加限速；整体音效音量降一档 | 音频 |
| F1 | 字体全用像素体，包括标题 | 所有文字（标题、封面、分享卡、按钮、大字）都用 Fusion Pixel；字号尽量用 12 的倍数保证清晰 | 音频 + 字体 |
| A1 | 每个房间地板壁纸不一样；西馆和主馆一模一样 | 15 间房各有一套**地板 + 墙面**（榻榻米颜色 / 包边、木地板、地毯；白灰泥颜色、壁纸花纹、木板墙）；**西馆整体换风格**（和洋折衷「大正浪漫」：木地板 + 花地毯、花纹壁纸、台灯）；套房更豪华 | 美术 |
| A2 | 樱花树、枫树只有一棵 | 每次解锁种一小片（3~5 棵，大小错落），位置不挡路 | 美术 |
| A3 | 下面的花园（猫在睡觉）没完成 | 把这块做成完整的庭院：花坛、矮篱、石子路、长椅、小水钵 / 石灯笼、几只晒太阳的猫；以后 v2.1 祭典还能在这里摆摊 | 美术 |
| A4 | 两个温泉没差异 | 主温泉 = 岩石露天、碧绿水；星见汤 = 桧木平台 + **乳白色的汤**（或淡蓝夜空倒影）、木桶边、竹灯；水面动画也不一样 | 美术 |
| A5 | 四季 | v2.1 第 16.1 节的四季日历 + 季节美术（樱 / 夏绿 / 枫红 / 雪），**第二轮做** | 第二轮 |
| A6 | 老板的衣服 | 狸老板百货加掌柜服装（几套法被配色、浴衣、和服、季节限定），试衣镜换装，**第二轮做** | 第二轮 |
