# 有意义的玩法 · 设计提案（Meaningful Play）

> 猫猫温泉旅馆 v2。视角：玩家从 ★1 到 ★5、再到五星之后，**每一分钟在干什么**，怎么才不会变成「一直走去踩鱼干」。
> 回应用户反馈：重复（#2）、房间没差别（#3）、★2~★5 没差别 + 地方太小（#4 #10）、台词（#6）、买了不知道买了啥（#7）、五星后的无尽模式和大额消费（#9），开罗元素（#8）贯穿全文。
> 约定：玩家看到的字一律中文；数值是初值，交给机器人调（§12），和经济视角的数值以机器人结果为准对齐。坐标是新地图（§2）的格子坐标，旧旅馆整体右移 12 列（`OX = 12`）。

## 0. 结论（5 条原则）

1. **每颗星 = 一个新地方 + 一种新动作**。★2 温泉（送毛巾、端茶）、★3 西馆食堂（做饭上菜）、★4 东馆别馆（迎宾带路、伺候愿望、合影）、★5 百货与庭院（试穿、收藏；R2 加旅行团、稀客）。不是「更多一样的房间」。
2. **雇一个员工接走一样日常活，同时冒出一样「只有掌柜能干」的特别活**。自动化让玩家去干更值钱、更有意思的事，而不是闲着。
3. **收钱减负**：招财猫（吸鱼干范围 3 级）+ 账房猫（把各处鱼干扛回前台）+ 特别活的钱直接进口袋。目标：★3 之后「走去踩鱼干」不超过 30% 时间。
4. **所有新事情都是软失败**：没送到、没伺候好 = 少拿小费。不生气、不扣钱、不卡关；不理贵宾他也会自己去房间、自己走。
5. **少字**：图标气泡、箭头旁的小图标、一行说明卡（≤9 字）、台词（≤8 字、同屏最多 1 句）。不晃屏、不自动挪镜头。

## 3. 新系统（规则 + 数值）

### 3.1 托盘：头顶毛巾 + 手上托盘（多种东西）

- **头顶 = 毛巾摞**（不变，容量 4 / 7 / 10）。
- **手上 = 托盘**，一份一份的东西，可以混装：🍵 茶、🥛 牛奶、🍙 饭团（早饭 / 夜宵同一样）、🍱 会席（金色食盒，只给贵宾）。容量 2 → 3 → 4（「托盘」圈 2 级）。
- **取物点**（站进去自动拿）：

| 取物点 | 给什么 | 速度 |
|---|---|---|
| 茶台 ×2 | 🍵 | 0.3 s / 份 |
| 牛奶机买奶位 | 🥛 | 0.3 s / 份 |
| 出餐台 | 🍙 | 0.15 s / 份（厨师做好的） |
| 灶台（没厨师） | 🍙 | 1.0 s / 份 |
| 灶台（贵宾要会席时） | 🍱 | 3 s，金色进度圈，厨师不会做 |

- **只拿有人要的**：每个取物点只给到「正在等这样东西的人数 − 托盘里已有的」为止（至少 1 份）。托盘永远不会被没用的东西塞满。
- **放回**：托盘里没人要的东西（呼叫过时了），站进任何取物点就「啵」地放回去。
- **递交**：走到要它的人 14 像素内，0.2 秒自动递过去（叮 + 那份东西飞过去）。
- 画法：托盘在胸前（正面 / 侧面），每份 5×4 小图标；朝上走时托盘画在头侧。头顶毛巾照旧。

### 3.2 呼叫铃（★2 起，玩家专属）

- **开启**：买「茶台」（前台之后，70 鱼干）。
- **谁叫、叫什么**：
  - 客人在客房躺下 1 秒后，按房型几率叫一次：标准 30%、庭园 45%、书院 35%、景观 35%。标准 / 庭园 → 🍵；书院 → 🍙 夜宵（没食堂时 🍵）；景观 → 🥛 或 🍙（缺哪样就换 🍵）。
  - 泡汤客下水时 20% 叫 🥛（有牛奶机才叫）。
- **上限**：★2 同时 2 个，★3 起 3 个；两次新呼叫至少隔 6 秒。
- **时限**：🍵 25 秒，🍙 30 秒，🥛 20 秒。
- **呼叫跟着客人走**：客人照常睡醒、去泡汤、去吃饭，铃铛气泡跟着他；追上去递也算。**不多占房间、不占泡汤位**（吸取「长支线别占稀缺资源」的教训）。
- **显示**：客人头顶金边铃铛气泡，里面画要的东西；边色按剩余时间 白 → 橙 → 红。躺在被褥里时气泡在被褥上，房门的小铃也亮（走廊里看得到）。顶栏多一个「🔔2」小药丸（>0 才显示）。
- **奖励**：呼叫小费 = 4 × 当星小费（★2 20 / ★3 24 / ★4 32 / ★5 40），**直接进口袋**（鱼干从客人头顶飞到顶栏）+ ♥1；在前一半时间内送到 ×1.5，客人说「好快！谢谢」。
- **过时**：气泡缩掉，50% 说「唉，算了」。不生气、不计入 angry、照常付房费。
- 员工永远不接呼叫。

### 3.3 食堂（★3 新动作：做饭、上菜）

- 买「食堂」：西拱门暖帘升起，西馆亮起，4 张饭桌。
- 客人流程加一段：睡 → 温泉 → 牛奶 → **食堂** → 离开。有空座才去；没空座直接走，不排队。
- 坐下：头顶 🍙 气泡，耐心 30 秒（白→橙→红）。
- 上菜：托盘里有 🍙，走到他身边 → 吃 4 秒（筷子两帧）→ 付早饭钱到食堂鱼干堆 + ♥ + 台词。
- 做饭：没厨师时站灶台 1 秒一份；有厨师时厨师每 2.5 秒往出餐台放一份（最多 6），玩家 / 跑堂去出餐台拿。
- 没吃到：30 秒后起身走，「下次吧…」，不付早饭钱、不算生气。
- 员工：**厨师**（黑猫，白厨师服 + 高帽）自动做；**跑堂**（奶牛猫，蓝前挂）一次端 2 份自动上菜，空闲站 (6,26)。两个都雇了，食堂全自动，玩家只剩夜宵呼叫和会席。
- 早饭钱：★3 12 / ★4 15 / ★5 20。

### 3.4 收钱减负

- **招财**（3 级圈，在 (14,24) 同一个位置升级）：踩鱼干判定从「±10 像素方框」改成「半径 R 的圆」：10 → 18 → 28 → 40。R=40 时站在房门口就能吸走房里的小费。买下时从掌柜身上放出一圈半透明圆，显示新范围（0.6 秒）。
- **账房猫**（老灰猫 + 圆眼镜 + 布袋）：任何一堆鱼干 ≥ 2 × 小费、且离玩家 > 48 像素 → 认领最老的那堆，走过去装袋，扛回前台倒进前台堆。钱在装袋那一刻就记进前台堆（存档一致），路上的袋子只是画面。前台堆 > 200 时画成大钱袋。结果：后期偶尔踩一下前台就行。
- **特别活的钱直接进口袋**（呼叫、贵宾、旅行团）。
- **顶栏进度条**：鱼干数字下面一条 2 像素细条 = 身上的钱 / 最便宜的可见价格圈还差的钱，末端画那个圈的 7×7 小图标；够了变金色。等钱的时候也看得见「快了」。

### 3.5 贵宾（★4 新动作：迎宾、带路、伺候、合影）

- **开启**：买「别馆」，东馆 + 别馆庭院 + 套房 A 亮起。第一位贵宾在买下 20 秒后到（固定是猫川先生）；之后每 210±30 秒（★5 180 秒；有套房 B 再 ×0.7）。**同时只有一位贵宾**。
- **到店**：从大门走到红毯位 (19,26)，身后拖金色小光点，三音「叮叮当」；头顶金色名片气泡。不排队，前台猫不接（掌柜亲自迎）。
- **迎宾**：走到他身边 14 像素内站 0.5 秒（金色进度圈）→「劳烦带路」→ 他跟着你。
- **带路**：贵宾踩着你的脚印走（面包屑轨迹，不用寻路），落后你 16 像素。路程距离 > 96 像素就停下冒「…」+「慢点走嘛」，箭头改指向他；回去接他就继续。没有失败。
- **入住**：走到套房站位 → 他坐下；套房门上方出现「愿望牌」：3 个图标一排，当前那个金边、轻轻上下浮。
- **4 种愿望**（每位贵宾固定 3 个，最后一个永远是合影）：

| 图标 | 掌柜要做的 |
|---|---|
| 🍵 喝茶 | 托盘端一份茶给他（东馆茶台最近） |
| ♨ 私汤 | 站在汤桶旁放水位 1.5 秒 → 他泡 5 秒（热气），这 5 秒你可以去干别的 |
| 🍱 会席 | 站灶台 3 秒（金色进度圈）→ 金色食盒 → 端给他 |
| 📷 合影 | 站他身边 1.2 秒 →「咔嚓」，一张拍立得从他头上飞向顶栏「菜单」键，进图鉴 |

- **奖励**：贵宾礼 G = ★4 300 / ★5 500。每完成一个愿望先给 25%（直接进口袋）；合影后给剩下的 × 速度系数 `0.6 + 0.4 × clamp(1 − (用时 − 90) / 120, 0, 1)`。+♥5。礼物摆上纪念品架。
- **软失败**：60 秒没人迎 → 自己走去套房；坐下后 120 秒没进展 →「改日再访」离开，给 30% 礼。离开后套房变脏（仲居会扫，打扫时间 ×2）。
- **6 位名人**（按顺序来，来齐后随机重访，图鉴记次数）。帽子道具和 §6 的帽子共用一套精灵：

## 7. 箭头 v2（`guideTarget()`，同时是机器人的大脑）

规则不变：**指的地方必须真能推进**；箭头旁多画一个 7×7 小图标说明去干嘛（🍵 🥛 🍙 🍱 ♨ 📷 ★名片 🧹 🐟 🧺），玩家不用读字。目标是会动的客人时每 0.25 秒更新，但有黏性：只有别的目标「紧急度高 30% 以上」才换，防止箭头来回跳。

1. 还没走过路 → 不画箭头，画拖动小手（不变）。
2. **正在干的活继续干**（`here`，不画）：接待位有客人要接（没前台时）；脏房打扫区；篮子 / 毛巾架（同旧规则）；灶台正在做有人等着的饭或会席；出餐台 / 茶台 / 买奶位正在拿有人要的东西；贵宾身边正在迎宾 / 合影；放水位；正在倒钱。
3. **贵宾**（同时只有一位）：
   a. 在红毯等 → 贵宾（★名片）；
   b. 跟着但落后 > 96 像素 → 贵宾；
   c. 跟着 → 套房站位；
   d. 坐下了：当前愿望 🍵 → 托盘有茶 ? 贵宾 : 最近的茶台；♨ → 放水位；🍱 → 托盘有会席 ? 贵宾 : 灶台；📷 → 贵宾。
4. **托盘里有别人正等着的东西** → 那个人（最急的、来得及的）。
5. 1~3 步内的鱼干堆（不变）。
6. **有来得及的呼叫** → 没拿着就去取物点，拿着就去客人。「来得及」= 取物点路程 + 到客人路程（BFS 格数 × 16 / 速度）× 1.2 < 剩余时间。来不及的不指（不指注定失败的事）。
7. 头顶有毛巾、没搬运猫、篮子 ≤ 2 或有人等毛巾 → 篮子（不变）。
8. 买得起的价格圈 → 最便宜的（只算进度圈；百货展台每件只在**第一次**买得起时指一次）。
9. 没前台、有客人在柜台 / 走过来、有空房 → 接待位（不变）。
10. 最大那堆鱼干加身上的钱够买某个可见的圈 → 那堆（不变）。
11. 食堂有人等饭、没跑堂：出餐台有饭 → 出餐台；没厨师 → 灶台（拿到后由第 4 条接着指客人）。
12. 有客人因为没干净房在等、脏房数 > 仲居数 → 最近的脏房（不变）。
13. 毛巾（没搬运猫时，不变）。
14. 最大的鱼干堆（≥ 20 且 ≥ 最便宜可见圈差额的 10%，避免为 5 条鱼干横穿地图）。
15. 身上有钱 → 最便宜的可见进度圈（先倒一部分）。
16. 有客人在等、房全满 → 最先醒的那间（不变）。
17. 无尽模式什么都没有 → 不画（让玩家自在地逛、摸鱼）。

## 12. 无头机器人要测什么

在 `tests/bot_balance.js` 上扩：机器人认得新目标（`vip` 走到身边；带路时直接走去套房，贵宾自己跟；`stove` `pass` `urn` `tap` `photo` 站进去；`caller` / `diner` 是会动的目标，每 0.25 秒重新取位置）。新档位 `ignore`：从不做呼叫 / 贵宾（验证不做特别活也能慢慢通关）。

| # | 指标 | 目标 |
|---|---|---|
| 1 | 各星、各圈的达成时间 | eager ★2 2:00~2:40、★3 10~13、★4 18~22、★5 28~34 分；casual ★5 ≤ 42；novice ≤ 70；ignore ≤ eager × 1.4 |
| 2 | 解锁间隔 | eager 前 5 分钟 ≤ 60 s，之后 ≤ 100 s；casual ≤ 130 s |
| 3 | **活动占比**（每 3 分钟一窗）：去踩鱼干 / 接待 / 打扫 / 毛巾 / 做饭上菜 / 呼叫 / 贵宾 / 倒钱 / 没目标 | ★2 + 3 分钟后「去踩鱼干」≤ 30%；★3 起「呼叫 + 上菜 + 贵宾」≥ 25%；5 分钟后任何一项单独 ≤ 50%；★5 前「没目标」≤ 10% |
| 4 | **新鲜事间隔**：买圈、第一次新动作、贵宾到、新名人、旅行团 | 任意两件之间 ≤ 150 s |
| 5 | 呼叫：每分钟生成数、完成率、中位反应时间、过时率、快送比例 | eager 完成 ≥ 85%，casual ≥ 50%；快送 40~60% |
| 6 | 食堂：上菜率、中位等待、没吃到率 | 没厨师时 eager 没吃到 ≤ 25%；有跑堂后 ≤ 5% |
| 7 | 贵宾：迎宾 → 合影用时、停下等的次数、速度系数 | eager 中位 60~100 s；系数中位 ≥ 0.85 |
| 8 | 收入分来源（房、小费、泡汤、牛奶、早饭、呼叫、贵宾、团）+ 特别活占比 | ★4~★5 特别活占 20~35%（有意义但不强迫） |
| 9 | 台词：每分钟条数、同屏最多几条、60 秒内重复 | 4~8 条/分；同屏恒为 ≤1；重复 0 |
| 10 | **箭头有效性**：机器人到达目标后 5 秒内真的推进了（接到客、扫完、拿到、递出、倒进钱） | ≥ 95%；箭头 5 秒内换目标 > 3 次的次数 ≈ 0 |
| 11 | 无尽 120 分钟（eager 会去买展台）：每件的买下时间、相邻两次「想要的」购买间隔、闲钱 / 下一件价格 | 第 1 小时间隔中位 ≤ 8 分钟；闲钱很少长期 > 2 × 下一件 |
| 12 | 挂机 10 分钟（★3 / ★4 / ★5 各一次） | 不卡死；收入 ≥ 主动玩的 50%；呼叫干净过时、贵宾自己入住和离开、食堂没吃到的客人正常离开 |
| 13 | 不变量（每秒） | 钱是 ≥0 整数；托盘 ≤ 容量、只有已知种类；每个座位 ≤ 1 人；每间套房 ≤ 1 位贵宾；同时贵宾 ≤ 1；贵宾任一状态 ≤ 300 s；跟随者离领队 ≤ 200 像素或在「等」状态；客人任一状态 ≤ 180 s（睡、泡、吃这类固定时长除外）；鱼干堆 id 合法；`render()` 不抛错 |
| 14 | 存档往返：在贵宾进行中 / 有呼叫 / 托盘有东西 / 旅行团中 存 → 新开 → 读 → 跑 5 分钟 | 钱、解锁、peak 不变；贵宾半礼进了前台堆；不报错 |
| 15 | 镜头 / 闪烁 | 没有任何非玩家输入导致的镜头移动；任何东西闪烁 ≤ 5 次/秒 |

## 14. 风险与取舍

- **画面太挤**：同屏台词 ≤1、价格圈 ≤4、屏幕边标记 ≤2、图标气泡只有一层；图示卡和说明卡共用底部一个位置。
- **★3 没厨师那一分钟太忙**：没吃到饭不罚；厨师圈便宜（450）且紧跟食堂；箭头先保证接待和扫房不卡。
- **地图变大走路变多**：两翼都贴着大堂；东馆第二个茶台；日常活后期全给员工；贵宾路程算在「值得跑」的大单里。若机器人显示走路占比 > 35%，先加第 4 双跑鞋或把东馆茶台再挪近，不缩地图。
- **贵宾太「必须」**：贵宾钱占比目标 ≤ 15%；`ignore` 档必须能在 eager × 1.4 内到 ★5。
- **会动的箭头目标来回跳**：0.25 秒更新 + 30% 黏性阈值；机器人测「5 秒内换 >3 次」。
- **开罗元素接口**（给开罗视角对齐）：名人来访 = 贵宾；团体客 = 旅行团；人气等级 + ♥ = 评价；季节、祭典；房间改装的相邻组合加成；员工各有专职。
- **其他视角接口**：BGM（可以每升一星加一层乐器，贵宾 / 祭典有专属短乐句）、菜单（本提案需要「📖 图鉴」「🛍 已购」「💬 台词」三页 / 开关）、世界视角（若地图另有方案，本文的系统只依赖：西边一个带灶台和 4~6 张桌的食堂、东边一个离大堂 ~30 格以内的 1~2 间套房、一个百货大厅、庭院里若干装饰空地）。
