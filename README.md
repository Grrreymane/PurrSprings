# 猫猫温泉旅馆 Purr Springs

![猫猫温泉旅馆 Purr Springs](cover.png)

开一家猫猫温泉旅馆：接客、打扫、端茶上菜、迎接名人贵宾，从一星小馆扩建成五星温泉乡。

**在线试玩：** https://grrreymane.github.io/PurrSprings/

## v2.0 新内容

- **旅馆变大了**：地图扩到 40×36，每升一星开一块新地方（温泉、杂货铺、食堂、西馆、庭园、别院、贵宾套房、星见露天汤），13 间客房 + 2 间套房。
- **每颗星一个新玩法**：端茶送奶（呼叫铃）、做饭上菜、迎贵宾（带路 → 三个愿望 → 合影）；两件摆设凑成组合，客房变成主题房。
- **开罗式经营**：人气榜和 9 家对手旅馆、有名字会升级的员工、「新！」「组合！」横幅、图鉴；猫猫们会说话（菜单里可关）。
- **买了啥一眼就懂**：走近价格圈有说明卡和预览，买下有横幅和一句台词；右上「⏸ 菜单」能暂停、调声音、翻图鉴和「已购」。
- **五星后的无尽模式**：冲金★、去狸老板百货试戴帽子和宠物、往门前 100 万的金招财猫像里倒鱼干。
- **新音乐**：每个区域一首曲子，昼夜换编配，变奏轮着来；v1 的存档会自动升级。

## 怎么玩

- 按住屏幕拖动＝摇杆走路（电脑上 WASD / 方向键），站到哪儿就自动干活。
- 跟着黄色小箭头走：接客、打扫、捡鱼干、送东西，它总指着眼下最有用的事。
- 客人头上冒气泡就是在叫你：去拿对应的东西送过去。
- 背着鱼干站进地上的虚线价格圈，就能扩建、雇员工、买摆设；买下「大门」就升一星。

## 本地运行

整个游戏是一个 `index.html`，没有构建步骤，直接用浏览器打开即可（或 `python -m http.server` 后访问）。进度保存在浏览器本地存储里。

改了游戏里的文字后运行 `python D:/Minigame/_workflow/tools/subset_font.py .` 更新字体子集。

测试：`node D:/Minigame/_workflow/tools/headless.js . tests/smoke.js --seed 1`（冒烟）；`node tests/balance_all.js`（平衡机器人，12 个种子 × 7 档玩家，对照 `docs/SPEC_v2.md` 14.2 的目标）。设计文档见 `docs/SPEC_v2.md`。
