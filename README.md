# 猫猫温泉旅馆 Purr Springs

![猫猫温泉旅馆 Purr Springs](cover.png)

开一家猫猫温泉旅馆：接客、打扫、端茶上菜、迎接名人贵宾，从一星小馆扩建成五星温泉乡。

**在线试玩：** https://grrreymane.github.io/PurrSprings/

## v2.1「温泉乡四季」新内容

- **四季轮转**：一季 3 天、一年 72 分钟。樱花瓣、夏夜萤火虫、红叶、雪，每季有自己的收费加成、季节摆设和组合。
- **祭典和来客**：每季一次祭典（入住点灯笼、夏天放烟花），记者 / 电视台来打分，年底颁年度大赏，五星后猫妈妈每年春天来拍全家福。
- **两块新地方**：西北的猫神社（10 级奉纳，一级比一级气派），东南的祭典广场（屋台夜市 + 花钱放一场烟花）。
- **庭院摆设引来稀客**：8 件摆设各引来一位稀客（禅师、狐新娘、小猫三兄弟……），新愿望「陪站」「带去看」，留下纪念品。
- **狸老板百货完整版**：掌柜的 8 套衣服、员工制服、小狐 / 小狸 / 白鹤、金摆设；菜单新增「装扮」页、图鉴分页和小地图。

## v2.0 新内容

- **旅馆变大了**：地图扩到 40×36，每升一星开一块新地方（温泉、杂货铺、食堂、西馆、庭园、别院、贵宾套房、星见露天汤），13 间客房 + 2 间套房。
- **每颗星一个新玩法**：端茶送奶（呼叫铃）、做饭上菜、迎贵宾（带路 → 三个愿望 → 合影）；两件摆设凑成组合，客房变成主题房。
- **开罗式经营**：人气榜和 9 家对手旅馆、有名字会升级的员工、「新！」「组合！」横幅、图鉴；猫猫们会说话（菜单里可关）。
- **买了啥一眼就懂**：走近价格圈有说明卡和预览，买下有横幅和一句台词；右上「⏸ 菜单」能暂停、调声音、翻图鉴和「已购」。
- **五星后的无尽模式**：冲金★、去狸老板百货试戴帽子和宠物、往门前 100 万的金招财猫像里倒鱼干。
- **新音乐**：每个区域一首曲子，昼夜换编配，变奏轮着来；v1 的存档会自动升级。

## 怎么玩

- 按住屏幕拖动＝摇杆走路（电脑上 WASD / 方向键），站到哪儿就自动干活。
- 跟着黄色小箭头走：接客、打扫、捡鱼干、送东西，它总指着眼下最有用的事。
- 客人头上冒气泡就是在叫你：去拿对应的东西送过去。
- 背着鱼干站进地上的虚线价格圈，就能扩建、雇员工、买摆设；买下「大门」就升一星。

## 本地运行

发布的整个游戏是一个 `index.html`，直接用浏览器打开即可（或 `python -m http.server` 后访问）。进度保存在浏览器本地存储里。

游戏代码在 `src/`：改完运行 `npm run sync` 写回 `index.html`，再 `npm test`（Node 18+，没有依赖要装）。目录和规则见 `docs/source-layout.md`、`AGENTS.md`。

改了游戏里的文字后运行 `python D:/Minigame/_workflow/tools/subset_font.py .` 更新字体子集。

测试：`npm test`（布局 + 同步检查 + 冒烟 / 地图 / 界面）；单个测试 `node D:/Minigame/_workflow/tools/headless.js . tests/smoke.js --seed 1`；`node tests/balance_all.js`（平衡机器人，12 个种子 × 7 档玩家，对照 `docs/SPEC_v2.md` 14.2 的目标）。设计文档见 `docs/SPEC_v2.md`。
